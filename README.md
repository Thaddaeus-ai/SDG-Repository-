# SDG Repository: PollutionTracker (Satellite Cafe)

Web application where Cagayan de Oro residents report water pollution and carbon-emission sources, log daily carbon activity, view climate information, and read educational articles. Supports SDG 13 (Climate Action) and SDG 4 (Quality Education).

## API design
The final OpenAPI 3.0.3 specification is `ITCC14API_SatelliteCafe_Final.yaml` (copy it to `docs/openapi.yaml`). Open it in Swagger Editor to view and validate.

## Frontend
Static pages styled by `style.css` (`index.html`, `reports.html`, `carbon.html`, `learn.html`). Climate and air-quality data come directly from Open-Meteo; all other data comes from the API.
